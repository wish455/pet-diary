# 🐾 铲屎官日记 · 宠物管理系统

一个自托管的多用户宠物管理网站：宠物档案、日常日记、健康管理、喂食计划、猫饭狗饭自制食谱、提醒待办与成长相册。
功能参考 [铲屎官日记（seeyoudiary.com）](https://www.seeyoudiary.com/index/) 并扩展为完整系统。

**零第三方依赖** —— 只用 Node.js 内置模块（`node:http` + `node:sqlite`），不需要 `npm install`，不需要联网，数据保存在自己的 SQLite 文件里。
既可以在自己电脑上单机用，也可以部署到公网给朋友用（账号之间数据完全隔离）。

---

## 一、本机使用

```bash
npm start          # 等价于 node server/index.js
```

然后浏览器打开 <http://127.0.0.1:3000>，**注册第一个账号**（自动成为管理员）即可开始。
Windows 用户也可以直接双击 **`启动网站.bat`**。

想要一份现成的示例数据（3 只宠物、10 条日记、健康记录、喂食计划、食谱、提醒）：

```bash
npm run seed       # 数据库为空时写入示例数据
npm run reset      # 清空后重新写入示例数据
```

示例数据会归属到演示账号 **demo / demo12345**（管理员），登录后请立即改密码。

## 二、部署到公网给其他人用

完整图文步骤见 **[docs/部署到公网.md](docs/部署到公网.md)**，三种方式任选：

| 方式 | 适合 | 成本 |
| --- | --- | --- |
| Render / Railway / Fly.io（连 GitHub 自动部署） | 想最快上线 | 免费可试，带持久磁盘约 $5–7/月 |
| 自己的云服务器 + 域名（Docker + Caddy/Nginx） | 长期使用、数据在自己手里 | 服务器几十元/月起 |

两种方式都提供：自动 HTTPS、`/healthz` 健康检查、持久化数据目录（`DATA_DIR`）、环境变量配置。

## 四、账号与安全

- **多用户隔离**：每个账号只能读写自己的宠物与记录。所有接口在服务端按 `user_id` 过滤；越权访问他人记录返回 404，往他人宠物下写数据同样被拒绝。
- **首个账号即管理员**：可在「数据中心 → 账号管理」停用/启用其他账号（停用会立即让对机会话失效）。
- **注册控制**：`OPEN_REGISTRATION=0` 关闭注册；`INVITE_CODE=xxx` 要求邀请码；`ADMIN_USERS=用户名` 提升管理员。
- **口令安全**：scrypt 加盐哈希（`N=16384`），登录失败 10 分钟窗口内超过 8 次自动限流。
- **会话**：HttpOnly + SameSite=Lax Cookie，生产环境自动加 Secure；过期会话定期清理。
- **上传**：只接受 JPG/PNG/WebP/GIF（拒绝可内嵌脚本的 SVG），按用户分目录存放，默认单张 8MB 上限。
- **响应头**：CSP、X-Frame-Options、nosniff、Referrer-Policy、Permissions-Policy，生产环境额外发送 HSTS。
- **备份隔离**：导出的 JSON 只含自己账号的数据；导入会重新分配主键并重建关联，**不会覆盖或串改其他账号的记录**。

## 五、环境变量

复制 `.env.example` 参考，或在部署平台的环境变量里设置：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` / `HOST` | `3000` / 生产 `0.0.0.0` | 监听端口与地址 |
| `DATA_DIR` | `./data` | 数据库与上传图片目录（容器部署指向挂载卷 `/data`） |
| `NODE_ENV` | — | `production` 时开启 HTTPS Cookie 与 HSTS |
| `COOKIE_SECURE` | 生产 `true` | 用 `https://` 访问保持 `true`；纯 `http://` 调试设 `false` |
| `SESSION_DAYS` | `30` | 登录状态保持天数 |
| `OPEN_REGISTRATION` | `1` | `0` 关闭注册 |
| `INVITE_CODE` | 空 | 填写后注册需邀请码 |
| `ADMIN_USERS` | 空 | 逗号分隔，启动时提升为管理员 |
| `MAX_UPLOAD_MB` | `8` | 单张图片上限 |

## 七、数据与备份

- 数据库：`data/pet.db`（SQLite，WAL 模式）
- 上传图片：`data/uploads/u<用户id>/`
- 换电脑 / 重装 / 迁移：在「数据中心」导出自己的 JSON 再导入；整站迁移可直接拷贝整个 `data` 目录（含所有账号）。

## 九、营养算法的口径

- 每日静息能量 `RER = 70 × 体重(kg)^0.75`，`DER = RER × 生理阶段系数`（成猫已绝育 1.2、成犬已绝育 1.6、幼年 2.5~3.0 等）
- 钙磷比建议 1.1~1.3 : 1；无骨肉配方按每 100g 肉补 0.8~1g 蛋壳粉
- 猫粮必须额外补充牛磺酸，且需在关火后添加（不耐高温）
- 食材营养值取自公开食物成分表的通用参考值，**用于家庭配餐的粗略估算，不能替代兽医营养师处方**；长期全自制建议使用营养预混粉并定期体检。
